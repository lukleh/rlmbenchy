# Reference Material

## Recursive Language Models

The converted paper text and extracted figures in this directory are derived
from *Recursive Language Models* by Alex L. Zhang, Tim Kraska, and Omar
Khattab:

- [arXiv:2512.24601v2](https://arxiv.org/abs/2512.24601v2), represented by
  `2512.24601v2.md` and the `_page_*` extracted figures.
- [arXiv:2512.24601v3](https://arxiv.org/abs/2512.24601v3), represented by
  `2512.24601v3.md` and the `2512.24601v3_assets/` extracted figures.
